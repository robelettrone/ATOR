# ATOR — Another Calculator (v1.0.0)

Scientific and programmer desktop calculator for Windows and Linux with exact fraction & symbolic arithmetic, binary/octal/decimal/hexadecimal radices, unit conversions, expression history, and persistent session state.

- **Official Website:** https://ator-calculator.web.app
- **Downloads:** [Latest Release (v1.0.0)](https://github.com/robelettrone/ATOR/releases/latest)
- **Support:** [Buy me a coffee](https://buymeacoffee.com/roborante)

> This repository hosts official binary releases only (no source code).

## Install

- **Windows 10/11 (64-bit):** Download and run `ATOR-Setup-1.0.0-win64.exe`
- **Linux (Debian / Ubuntu amd64):**
  ```bash
  sudo apt install ./ator_1.0.0_amd64.deb
  ```
